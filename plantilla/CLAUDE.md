# Proyecto construido con proyecto-loop

El loop vive adentro de este repo, en `.claude/`. La versión está en
`.claude/loop/VERSION`.

- Para arrancar o seguir: `/project-loop`.
- Para traer una versión más nueva del loop: `/loop-actualizar`.

El estado del loop está en `.loop/`. Lo leen y escriben las skills; no lo edites a mano.
