# Reglas de usuario (no las instala ninguna skill)

`ingenieria.md` es la copia versionada de lo que vive en `~/.claude/rules/ingenieria.md`.

Va al perfil personal, no a un repo: aplica a todos los proyectos de la máquina.
Se instala a mano:

```bash
mkdir -p ~/.claude/rules && cp ingenieria.md ~/.claude/rules/
```

Está acá para no perderlo: `~/.claude/` no está bajo control de versiones.
Si lo editás en el perfil, actualizá también esta copia.
